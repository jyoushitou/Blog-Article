## 关键要点

| 要点                      | 说明                                                                                                                    |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **字段名必须精确匹配**    | `slug`、`title`、`date`、`tags`、`summary` 一个都不能少，拼错会解析失败（返回 `None`，该文章被跳过）                    |
| **`tags` 是数组**         | 要么 `tags: [a, b]` 方括号一行，要么 `tags:` 换行用 `-` 列表                                                            |
| **所有值都是字符串**      | `date` 写字符串即可，`serde_yaml` 会把 YAML 日期（如 `2024-06-15`）解析成字符串也没问题                                 |
| **`---` 必须各占一行**    | 开头的 `---` 后面直接换行，结尾 `---` 后面紧接正文                                                                      |
| **文件名 = slug（建议）** | `read_article` 会读取 `article/{slug}.md`，所以文件名最好和 `slug` 一致，例如 `hello-world.md` 对应 `slug: hello-world` |

---

## 组织结构建议

```
Blog/article/
├── hello-world.md       ← slug: hello-world
├── rust-async-tutorial.md  ← slug: rust-async-tutorial
└── my-review-2024.md    ← slug: my-review-2024
```

每个文件都是：

```markdown
---
slug: 文件名
title: 标题
date: 日期
tags: [标签1, 标签2]
summary: 摘要内容
---

正文...
```
