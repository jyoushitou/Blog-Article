# proto（Protocol Buffers）

Protocol Buffers（简称 Protobuf / proto）是 Google 开源的一种**语言中立、平台中立、可扩展**的结构化数据序列化协议。开发者先用 `.proto` 文件定义数据结构（message）和服务（service），再用 `protoc` 编译器生成各语言的代码，用于序列化/反序列化以及 RPC 调用。

## 关键字

> Protobuf 的「关键字」分两类：**语法关键字**（grammar 保留，不能作字段名）与**内置选项名**（option name，技术上可作标识符，但强烈建议避免）。

### 1. 语法关键字（Grammar Keywords）

| 关键字           | 出现位置                                                       | 说明                                                     |
| ---------------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| `syntax`         | 文件首条语句                                                   | 声明 `"proto2"` 或 `"proto3"`                            |
| `edition`        | 文件首条语句                                                   | 声明 `"2023"` 等版本，与 `syntax` 二选一                 |
| `package`        | 文件级                                                         | 包名，决定生成代码的命名空间                             |
| `import`         | 文件级                                                         | 引入其他 `.proto` 文件                                   |
| `public`         | `import` 修饰                                                  | `import public "a.proto";` 使导入可传递                  |
| `weak`           | `import` / 字段修饰                                            | 弱引用，已废弃，勿用                                     |
| `option`         | 文件 / 消息 / 字段 / 枚举 / 枚举值 / oneof / 服务 / 方法 / rpc | 设置选项                                                 |
| `message`        | 顶层或嵌套                                                     | 定义消息类型                                             |
| `enum`           | 顶层或嵌套                                                     | 定义枚举                                                 |
| `service`        | 顶层                                                           | 定义 RPC 服务                                            |
| `rpc`            | `service` 内                                                   | 定义远程方法                                             |
| `returns`        | `rpc` 内                                                       | 声明返回类型                                             |
| `stream`         | `rpc` 参数或返回值前                                           | 流式 RPC（`stream Req` / `returns (stream Res)`）        |
| `oneof`          | `message` 内                                                   | 互斥字段组，同时最多一个被设置                           |
| `map`            | 字段类型                                                       | `map<key_type, value_type>`                              |
| `reserved`       | `message` / `enum`                                             | 保留编号或字段名，防止误复用                             |
| `to`             | `reserved` / `extensions`                                      | 区间连接词，如 `9 to 11`、`100 to max`                   |
| `max`            | `reserved` / `extensions`                                      | 区间上界，值为 536870911（2^29-1）                       |
| `extensions`     | `message`（proto2）                                            | 声明可被扩展的编号区间                                   |
| `extend`         | 顶层或嵌套（proto2 / 自定义选项）                              | 扩展已有消息，如 `extend google.protobuf.FieldOptions`   |
| `required`       | 字段（proto2）                                                 | 必填字段，proto3 已移除                                  |
| `optional`       | 字段                                                           | proto2 可选；proto3 显式声明以启用字段存在性（presence） |
| `repeated`       | 字段                                                           | 数组/列表，顺序保留                                      |
| `default`        | 字段选项（proto2）                                             | 指定默认值，如 `[default = 10]`                          |
| `group`          | 字段（proto2）                                                 | 已废弃的嵌套字段语法                                     |
| `true` / `false` | `option` 值、布尔默认值                                        | 布尔字面量                                               |

### 2. 标量类型关键字（同时是保留字）

| 类别 | 关键字                                                                                        |
| ---- | --------------------------------------------------------------------------------------------- |
| 整数 | `int32` `int64` `uint32` `uint64` `sint32` `sint64` `fixed32` `fixed64` `sfixed32` `sfixed64` |
| 浮点 | `float` `double`                                                                              |
| 其他 | `bool` `string` `bytes`                                                                       |

> `map` 的 key 只能是整数类型、`bool`、`string`；不能用 `float` / `double` / `bytes` / 枚举 / 消息。

### 3. 内置 option 名

**文件级**

| option                                                                                                    | 取值 / 说明                                   |
| --------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| `java_package`                                                                                            | 生成 Java 的包名                              |
| `java_outer_classname`                                                                                    | 外层类名（未开 `java_multiple_files` 时）     |
| `java_multiple_files`                                                                                     | `true` / `false`，每个 message 单独成类       |
| `java_string_check_utf8`                                                                                  | `true` / `false`                              |
| `optimize_for`                                                                                            | `SPEED`（默认）/ `CODE_SIZE` / `LITE_RUNTIME` |
| `go_package`                                                                                              | Go 包导入路径                                 |
| `cc_enable_arenas`                                                                                        | `true` / `false`                              |
| `csharp_namespace`                                                                                        | C# 命名空间                                   |
| `objc_class_prefix`                                                                                       | Objective-C 类前缀                            |
| `php_namespace` / `php_metadata_namespace` / `php_class_prefix`                                           | PHP 相关                                      |
| `ruby_package`                                                                                            | Ruby 模块名                                   |
| `swift_prefix`                                                                                            | Swift 前缀                                    |
| `deprecated`                                                                                              | `true` / `false`，标记过期                    |
| `java_generic_services` / `py_generic_services` / `cc_generic_services` / `java_generate_equals_and_hash` | 已废弃，勿用                                  |

**字段级**

| option            | 取值 / 说明                                                       |
| ----------------- | ----------------------------------------------------------------- |
| `default`         | 仅 proto2，字面量                                                 |
| `json_name`       | 自定义 JSON 字段名                                                |
| `packed`          | `true` / `false`，`repeated` 标量是否紧凑编码（proto3 默认 true） |
| `deprecated`      | `true` / `false`                                                  |
| `lazy`            | `true` / `false`，延迟解析（C++）                                 |
| `unverified_lazy` | `true` / `false`                                                  |
| `ctype`           | `STRING`（默认）/ `CORD` / `STRING_PIECE`，C++ string 表示        |
| `jstype`          | `JS_NORMAL`（默认）/ `JS_STRING` / `JS_NUMBER`，JS 中 int64 表示  |
| `weak`            | 已废弃                                                            |
| `debug_redact`    | `true` / `false`，调试输出脱敏                                    |

**消息级**

| option                            | 取值 / 说明                   |
| --------------------------------- | ----------------------------- |
| `message_set_wire_format`         | proto2，MessageSet 兼容编码   |
| `no_standard_descriptor_accessor` | proto2，不生成 `descriptor()` |
| `deprecated`                      | `true` / `false`              |
| `map_entry`                       | 编译器内部生成，用户不可手写  |

**枚举级**

| option        | 取值 / 说明                       |
| ------------- | --------------------------------- |
| `allow_alias` | `true` 允许不同枚举名使用相同数值 |
| `deprecated`  | `true` / `false`                  |

**服务 / 方法级**

| option              | 取值 / 说明                                              |
| ------------------- | -------------------------------------------------------- |
| `deprecated`        | `true` / `false`                                         |
| `idempotency_level` | `IDEMPOTENCY_UNKNOWN` / `NO_SIDE_EFFECTS` / `IDEMPOTENT` |

### 4. Editions（2023+）特性 option

| option                             | 取值                                        |
| ---------------------------------- | ------------------------------------------- |
| `features.field_presence`          | `EXPLICIT` / `IMPLICIT` / `LEGACY_REQUIRED` |
| `features.enum_type`               | `OPEN` / `CLOSED`                           |
| `features.repeated_field_encoding` | `PACKED` / `EXPANDED`                       |
| `features.utf8_validation`         | `VERIFY` / `NONE`                           |
| `features.message_encoding`        | `LENGTH_PREFIXED` / `DELIMITED`             |

### 5. 自定义选项相关

- `extend google.protobuf.FileOptions` / `MessageOptions` / `FieldOptions` / `EnumOptions` / `EnumValueOptions` / `ServiceOptions` / `MethodOptions` / `OneofOptions`：定义自定义 option。
- `option (my.opt) = 值;` 使用；聚合语法 `option (my.opt).sub = 值;`。
- `retention`：`RETENTION_UNKNOWN` / `RETENTION_SOURCE` / `RETENTION_RUNTIME`。
- `targets`：`TARGET_TYPE_*`（如 `TARGET_TYPE_FIELD`），限制自定义 option 可作用的位置。

### 6. 词法与标点

- 注释：`// 行注释`、`/* 块注释 */`
- 语句结束：`;`
- 选项列表：`[ ... ]`，多项用 `,` 分隔
- 消息体 / 服务体 / rpc 体：`{ ... }`
- 全限定名：`.package.Message`（前导点表示从根开始）
- `map` 泛型：`map<K, V>`

### 7. 完整保留字速查

| 分组       | 保留字                                                                                                                                                                                                                           |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 文件与结构 | `syntax` `edition` `package` `import` `public` `weak` `option` `message` `enum` `service` `rpc` `returns` `stream` `oneof` `map` `reserved` `to` `max` `extensions` `extend` `group`                                             |
| 字段修饰   | `required` `optional` `repeated` `default` `json_name` `packed` `deprecated` `lazy` `unverified_lazy` `ctype` `jstype` `debug_redact`                                                                                            |
| 标量类型   | `double` `float` `int32` `int64` `uint32` `uint64` `sint32` `sint64` `fixed32` `fixed64` `sfixed32` `sfixed64` `bool` `string` `bytes`                                                                                           |
| 字面量     | `true` `false`                                                                                                                                                                                                                   |
| Editions   | `features` `field_presence` `enum_type` `repeated_field_encoding` `utf8_validation` `message_encoding` `EXPLICIT` `IMPLICIT` `LEGACY_REQUIRED` `OPEN` `CLOSED` `PACKED` `EXPANDED` `VERIFY` `NONE` `LENGTH_PREFIXED` `DELIMITED` |

> 注意：proto3 中 `required`、`group`、`extensions`、普通场景的 `extend`、`default`、`weak` 均不可用；`optional` 自 proto3.15 起恢复支持（会生成 `has_xxx()`）。

### 8. 关键字全覆盖示例

下面这份 `.proto2`（便于演示 `required` / `group` / `extensions` / `default`）几乎用到了上表所有语法元素：

```proto
syntax = "proto2";   // 或改用 edition = "2023";（二者不可同时出现）

package demo.full;    // package

import "google/protobuf/descriptor.proto";
import public "common.proto";        // public：导入可传递
import weak "optional_dep.proto";    // weak：已废弃，仅作了解

// ---- 文件级 option ----
option java_package = "com.example.demo";
option java_outer_classname = "FullProto";
option java_multiple_files = true;
option java_string_check_utf8 = true;
option optimize_for = SPEED;          // SPEED | CODE_SIZE | LITE_RUNTIME
option go_package = "example.com/demo;demo";
option cc_enable_arenas = true;
option csharp_namespace = "Example.Demo";
option objc_class_prefix = "EXD";
option php_namespace = "Example\\Demo";
option ruby_package = "Example::Demo";
option deprecated = false;

// ---- 自定义 option（extend）----
extend google.protobuf.FileOptions  { optional string my_file_opt  = 50000; }
extend google.protobuf.FieldOptions { optional string my_field_opt = 50001; }
extend google.protobuf.MessageOptions { optional bool my_msg_opt = 50002; }
option (my_file_opt) = "hello";

// ---- 可被扩展的消息 ----
message Base {
  optional int32 a = 1;
  extensions 100 to 199;   // 预留扩展区间
  extensions 300 to max;   // max = 536870911
}

extend Base { optional string ext_str = 100; }

message All {
  option message_set_wire_format = false;
  option no_standard_descriptor_accessor = true;
  option deprecated = false;
  option (my_msg_opt) = true;

  required int32  f_required = 1;                                   // proto2 专属
  optional int32  f_optional = 2 [default = 7];                     // default
  repeated int32  f_repeated = 3 [packed = true];                   // packed
  optional string f_json     = 4 [json_name = "jsonKey", ctype = STRING];
  optional int64  f_js       = 5 [jstype = JS_STRING];
  optional string f_lazy     = 6 [lazy = true, unverified_lazy = false];
  optional bytes  f_redact   = 7 [debug_redact = true];
  optional string f_custom   = 8 [(my_field_opt) = "x"];

  map<string, int32> f_map = 9;                                     // map

  oneof choice {                                                    // oneof
    int32  c1 = 10;
    string c2 = 11;
  }

  optional group OldGroup = 12 { optional int32 g = 13; }           // group：已废弃

  reserved 14, 15, 20 to 22, 1000 to max;                           // 保留编号
  reserved "old_name", "f_removed";                                // 保留字段名

  enum Color {
    option allow_alias = true;    // 允许数值别名
    option deprecated = false;
    UNKNOWN = 0;                  // 首值建议为 0（proto3 中为强制要求）
    RED     = 1;
    CRIMSON = 1;                  // 与 RED 同值别名
    reserved 2, 5 to 8;
    reserved "BLUE";
  }
}

service FullService {
  option deprecated = false;

  rpc Unary        (Base)          returns (All) { option idempotency_level = NO_SIDE_EFFECTS; }
  rpc ClientStream (stream Base)   returns (All);   // 客户端流
  rpc ServerStream (Base)          returns (stream All); // 服务端流
  rpc BiDi         (stream Base)   returns (stream All) { option deprecated = true; }
}
```

> 说明：以上示例用于**语法演示**，直接编译需注意：
>
> - `common.proto`、`optional_dep.proto` 需自行创建；
> - `import weak` 已被新版 protoc 移除，仅作历史语法了解；
> - `group`、`required`、`extensions`、`default` 仅 proto2 可用；
> - 自定义 option 的编号应落在 `50000 ~ 99999`（`FieldOptions` 等扩展区间）以免冲突。

### 9. Editions 写法（2023 起）

```proto
edition = "2023";

package demo.ed;

option features.field_presence = EXPLICIT;            // 替代 optional
option features.enum_type = OPEN;
option features.repeated_field_encoding = PACKED;     // 替代 packed
option features.utf8_validation = VERIFY;

message M {
  int32  a = 1;  // EXPLICIT 下有 presence
  repeated int32 b = 2;
  int32  c = 3 [features.field_presence = IMPLICIT];
}
```

## 类型

### 1. 标量类型（Scalar Types）

| proto 类型 | 说明                                     | C++           | Java         | Python  |
| ---------- | ---------------------------------------- | ------------- | ------------ | ------- |
| `double`   | 64 位浮点                                | `double`      | `double`     | `float` |
| `float`    | 32 位浮点                                | `float`       | `float`      | `float` |
| `int32`    | 32 位有符号整数                          | `int32_t`     | `int`        | `int`   |
| `int64`    | 64 位有符号整数                          | `int64_t`     | `long`       | `int`   |
| `uint32`   | 32 位无符号整数                          | `uint32_t`    | `int`        | `int`   |
| `uint64`   | 64 位无符号整数                          | `uint64_t`    | `long`       | `int`   |
| `sint32`   | 32 位有符号（ZigZag 编码，负数更省空间） | `int32_t`     | `int`        | `int`   |
| `sint64`   | 64 位有符号（ZigZag 编码）               | `int64_t`     | `long`       | `int`   |
| `fixed32`  | 固定 4 字节无符号（大数更省空间）        | `uint32_t`    | `int`        | `int`   |
| `fixed64`  | 固定 8 字节无符号                        | `uint64_t`    | `long`       | `int`   |
| `sfixed32` | 固定 4 字节有符号                        | `int32_t`     | `int`        | `int`   |
| `sfixed64` | 固定 8 字节有符号                        | `int64_t`     | `long`       | `int`   |
| `bool`     | 布尔                                     | `bool`        | `boolean`    | `bool`  |
| `string`   | UTF-8 字符串                             | `std::string` | `String`     | `str`   |
| `bytes`    | 任意字节序列                             | `std::string` | `ByteString` | `bytes` |

### 2. 复合类型

- **message**：结构化消息，可嵌套定义，字段可标记 `required` / `optional` / `repeated`（proto2），proto3 默认为单值，`repeated` 表示数组，`map<K,V>` 表示映射。
- **enum**：枚举，第一个枚举值必须为 0（proto3）。
- **oneof**：同一时刻只允许其中一个字段被设置。
- **service / rpc**：定义 RPC 服务接口，用于 gRPC 等框架。
- **import**：引入其他 `.proto` 文件。

### 3. proto2 与 proto3 的区别

| 对比项    | proto2                                    | proto3                                 |
| --------- | ----------------------------------------- | -------------------------------------- |
| 字段规则  | 支持 `required` / `optional` / `repeated` | 移除 `required`，`optional` 需显式声明 |
| 默认值    | 可自定义                                  | 只支持类型默认值                       |
| 枚举首值  | 任意                                      | 必须为 0                               |
| 未知字段  | 保留                                      | 默认保留（3.5+）                       |
| JSON 映射 | 弱                                        | 内置规范映射                           |

## 作用

1. **高效序列化**：采用 TLV（Tag-Length-Value）+ Varint 编码，体积通常比 JSON/XML 小，解析速度更快。
2. **跨语言、跨平台**：同一份 `.proto` 可生成 C++、Java、Python、Go、C#、Rust 等多语言代码，天然适合作微服务通信协议。
3. **强类型与向后兼容**：字段用编号（tag）标识，新增字段不影响旧版本解析；删除字段只需保留编号（`reserved`），可实现平滑升级。
4. **IDL（接口定义语言）**：既是数据契约，也是服务契约，配合 gRPC 可自动生成客户端/服务端桩代码。
5. **可读的接口文档**：`.proto` 文件本身即可作为接口文档，配合注释与工具可生成 API 文档。

## 用法

### 1. 定义 `.proto` 文件

```proto
syntax = "proto3";

package demo;

option java_package = "com.example.demo";
option java_multiple_files = true;
option java_outer_classname = "UserProto";

message User {
  int64 id = 1;
  string name = 2;
  string email = 3;
  repeated string tags = 4;
  Gender gender = 5;
  map<string, string> attrs = 6;

  enum Gender {
    UNKNOWN = 0;
    MALE = 1;
    FEMALE = 2;
  }
}

service UserService {
  rpc GetUser (GetUserRequest) returns (User);
  rpc ListUsers (ListUsersRequest) returns (stream User);
}

message GetUserRequest {
  int64 id = 1;
}

message ListUsersRequest {
  int32 page = 1;
  int32 size = 2;
}
```

### 2. 安装编译器 `protoc`

```bash
# macOS
brew install protobuf

# Ubuntu / Debian
sudo apt-get install -y protobuf-compiler

# 查看版本
protoc --version
```

### 3. 生成代码

只生成**消息类**（用于序列化/反序列化）：

```bash
# C++
protoc --cpp_out=./gen -I. user.proto

# Java
protoc --java_out=./gen -I. user.proto

# Python
protoc --python_out=./gen -I. user.proto
```

若 `user.proto` 中定义了 `service`（下文示例使用 gRPC），还需额外生成**桩代码**：

```bash
# C++：需要 grpc_cpp_plugin
protoc --cpp_out=./gen --grpc_out=./gen \
  --plugin=protoc-gen-grpc=$(which grpc_cpp_plugin) -I. user.proto
# 生成 user.pb.cc/h 与 user.grpc.pb.cc/h

# Java：由 protoc-gen-grpc-java 插件生成（或用 Maven/Gradle 插件自动完成）
protoc --java_out=./gen --grpc-java_out=./gen \
  --plugin=protoc-gen-grpc-java=/usr/local/bin/protoc-gen-grpc-java -I. user.proto
# 生成 User.java / Gender.java / UserServiceGrpc.java 等

# Python：使用 grpcio-tools
python -m grpc_tools.protoc -I. \
  --python_out=./gen --grpc_python_out=./gen user.proto
# 生成 user_pb2.py 与 user_pb2_grpc.py
```

> 注意：Python 生成文件位于 `./gen`，运行示例前需设置 `export PYTHONPATH=./gen`（或 `sys.path.append("gen")`），否则 `import user_pb2` 会报 `ModuleNotFoundError`。

### 4. 常用规则与最佳实践

- 字段编号 `1 ~ 15` 使用 1 字节 tag，频繁使用的字段应分配小号。
- 不要随意修改或复用已删除字段的编号，使用 `reserved 5, 6;` 或 `reserved "old_name";` 保留。
- 字段编号一旦发布就不要再变更，否则会破坏兼容性。
- 枚举值建议保留 `0` 作为 `UNSPECIFIED` / `UNKNOWN` 默认值。
- 大文件可拆分多个 `.proto` 并用 `import` 组合，避免循环依赖。

## 示例（包含客户端和服务器端）

下面以 gRPC 为例，给出 C++、Java、Python 三语言的**服务端**与**客户端**示例。假设已有上面的 `user.proto` 并生成好代码。

### C++

**服务端 `server.cc`**

```cpp
#include <iostream>
#include <memory>
#include <string>
#include <grpcpp/grpcpp.h>

public:
    Status GetUser(ServerContext* context,
                   const GetUserRequest* request,
                   User* reply) override {
        reply->set_id(request->id());
        reply->set_name("张三");
        reply->set_email("zhangsan@example.com");
        reply->add_tags("vip");
        reply->set_gender(User::MALE);
        (*reply->mutable_attrs())["level"] = "gold";
        return Status::OK;
    }
};

void RunServer() {
    std::string address("0.0.0.0:50051");
    UserServiceImpl service;

    ServerBuilder builder;
    builder.AddListeningPort(address, grpc::InsecureServerCredentials());
    builder.RegisterService(&service);

    std::unique_ptr<Server> server(builder.BuildAndStart());
    std::cout << "Server listening on " << address << std::endl;
    server->Wait();
}

int main() {
```

```cpp
using grpc::ClientContext;
using grpc::Status;
using demo::User;
using demo::GetUserRequest;
using demo::UserService;

class UserClient {
public:
    explicit UserClient(std::shared_ptr<Channel> channel)
        : stub_(UserService::NewStub(channel)) {}

    void GetUser(int64_t id) {
        GetUserRequest request;
        request.set_id(id);

        User reply;
        ClientContext context;
        Status status = stub_->GetUser(&context, request, &reply);

        if (status.ok()) {
            std::cout << "id=" << reply.id()
                      << ", name=" << reply.name()
                      << ", email=" << reply.email() << std::endl;
        } else {
            std::cout << "RPC failed: " << status.error_message() << std::endl;
        }
    }

private:
    std::unique_ptr<UserService::Stub> stub_;
};

int main() {
    UserClient client(grpc::CreateChannel(
        "localhost:50051", grpc::InsecureChannelCredentials()));
    client.GetUser(1);
    return 0;
}
```

```java
import io.grpc.Server;
import io.grpc.ServerBuilder;
import io.grpc.stub.StreamObserver;
import com.example.demo.Gender;
import com.example.demo.GetUserRequest;
import com.example.demo.User;
import com.example.demo.UserServiceGrpc;

public class UserServer {
    static class UserServiceImpl extends UserServiceGrpc.UserServiceImplBase {
        @Override
        public void getUser(GetUserRequest request,
                            StreamObserver<User> responseObserver) {
            User reply = User.newBuilder()
                    .setId(request.getId())
                    .setName("张三")
                    .setEmail("zhangsan@example.com")
                    .addTags("vip")
                    .setGender(Gender.MALE)
                    .putAttrs("level", "gold")
                    .build();
            responseObserver.onNext(reply);
            responseObserver.onCompleted();
        }
    }

    public static void main(String[] args) throws Exception {
        Server server = ServerBuilder.forPort(50051)
                .addService(new UserServiceImpl())
                .build()
                .start();
        System.out.println("Server listening on 50051");
        server.awaitTermination();
    }
}
```

**服务端 `server.py`**

```python
from concurrent import futures
import grpc

import user_pb2
import user_pb2_grpc


class UserService(user_pb2_grpc.UserServiceServicer):
    def GetUser(self, request, context):
        return user_pb2.User(
            id=request.id,
            name="张三",
            email="zhangsan@example.com",
            tags=["vip"],
            gender=user_pb2.User.MALE,
            attrs={"level": "gold"},
        )


def serve():
    server = grpc.server(futures.ThreadPoolExecutor(max_workers=10))
    user_pb2_grpc.add_UserServiceServicer_to_server(UserService(), server)
    server.add_insecure_port("[::]:50051")
    server.start()
    print("Server listening on 50051")
    server.wait_for_termination()


if __name__ == "__main__":
    serve()
```
