# 面向对象

## 声明
```java
[修饰符] class <类名> [extends 父类名] [implements 接口列表]{
    //your code
}
```
### **[修饰符]**
|  修饰符名  |  访问权限  |              备注               |
| :--------: | :--------: | :-----------------------------: |
|   public   | 任意类使用 |          为访问控制符           |
|  abstract  |            |    抽象类，就是c++的纯虚函数    |
|   final    |   最终类   |           不能被继承            |
|   sealed   |   密封类   |       限定继承类(java17+)       |
| non-sealed | 解除密封类 | 仅用于 sealed 类的子类(java17+) |
### class <类名>
- **必须要有**
### **[extends 父类名]**
- 只允许单继承
>不要像c++那样一次性继承两个类
### **[implements 接口列表]**
>这个实现多态
>interface的关键字
## 类内部
### 声明变量
```java
[修饰符] [static] [final] <变量类型> <变量名>;
```
#### **[修饰符]**
>和c#类似，定义访问权限
| 修饰符名  |     权限     |
| :-------: | :----------: |
|  public   | 任何类可访问 |
| protected |  同包+子类   |
|  private  |  仅内部访问  |
#### **[static]/[final]**
|   名称    |                               含义                               |
| :-------: | :--------------------------------------------------------------: |
|  static   |             静态（属于类，不属于对象）—— 单独列出了              |
|   final   |                  最终（值不可改）—— 单独列出了                   |
| transient |              瞬态：序列化时跳过该字段，不参与序列化              |
| volatile  | 易变：多线程下保证可见性，每次读取都从主内存读（不能保证原子性） |
#### <变量类型> <变量名>
- **必须有**
