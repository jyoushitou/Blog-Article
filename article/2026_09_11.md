# java

# 编译java

```bash
javac yourjavaname.java
```

- 会在同级文件夹生成一个和你java同名的.class文件

# 运行

```bash
java yourclassname.class
```

- 就可以运行你编译好的文件

# 第一个文件HelloWorld

```java
public class HelloWorld{
    public static void main(String[] args){
        System.out.println!("HelloWorld");
    }
}
```

- 会输出HelloWorld

# 数据类型

## 常量

```java
final datatype CONSTANTNAME=value;
```

- 就定义了一个不可变变量
  > 等价于c++的**const datatype constant=value;**

### 整型

| 类型  | 位宽  |                    取值                    |
