# 面向对象

## 声明

```java
[修饰符] class <类名> [extends 父类名] [implements 接口列表]{
    //your code
}
```

- 感觉和c++很像啊

### **[修饰符]**

|  修饰符名  |  访问权限  |              备注               |
| :--------: | :--------: | :-----------------------------: |
|   public   | 任意类使用 |          为访问控制符           |
|  abstract  |            |    抽象类，就是c++的纯虚函数    |
|   final    |   最终类   |           不能被继承            |
|   sealed   |   密封类   |       限定继承类(java17+)       |
| non-sealed | 解除密封类 | 仅用于 sealed 类的子类(java17+) |

### class <类名>

- **必须要有**

### **[extends 父类名]**

- 只允许单继承
  > 不要像c++那样一次性继承两个类

### **[implements 接口列表]**

> 这个实现多态
> interface的关键字

## 类内部

### 声明变量

```java
[修饰符] [static] [final] <变量类型> <变量名>;
```

#### **[修饰符]**

> 和c#类似，定义访问权限
> | 修饰符名 | 权限 |
> | :-------: | :----------: |
> | public | 任何类可访问 |
> | protected | 同包+子类 |
> | private | 仅内部访问 |

#### **[static]/[final]**

|   名称    |                               含义                               |
| :-------: | :--------------------------------------------------------------: |
|  static   |             静态（属于类，不属于对象）—— 单独列出了              |
|   final   |          最终（值不可改）—— 单独列出了-等价于不可变变量          |
| transient |              瞬态：序列化时跳过该字段，不参与序列化              |
| volatile  | 易变：多线程下保证可见性，每次读取都从主内存读（不能保证原子性） |

#### <变量类型> <变量名>

- **必须有**

# 计算机组成原理

# 系统总线

## 解决问题

- 解决计算机内部的互相通讯线路过多的问题
- 解决设备之间连接接口空间占用过多的

## 概念

- 各部件共享的传输介质

## 传输方式

### 串行

- 一位一位的发和收
- 设备间的传输

### 并行

- 同时多位的收和发
- 距离短，易受干扰大

## 单总线结构图

```
-------------------------------
 |       |         |   ……     |
CPU     主存     I/O接口    I/O接口
                   |          |
                 I/O设备    I/O设备
```

## 面向CPU的双总线结构图

```
        ┌───────────────┐
        │               │────── 存储总线 ──────┐
        │      CPU      │                     │
        │               │                     ▼
        └───────┬───────┘                ┌─────────┐
                │                        │  主存   │
                │ I/O总线                └─────────┘
                │
        ┌───────┴───────┐
        │               │
     I/O接口         I/O接口
        │               │
     I/O设备         I/O设备
```

- **存储总线**：连接 CPU 与主存，专门负责 CPU 与主存之间的数据交换
- **I/O总线**：连接 CPU 与各 I/O 接口，负责 CPU 与外部设备之间的通讯
- 解决了单总线结构中所有部件争用同一总线导致的瓶颈问题

## 总线特性

### 机械特性

- 尺寸、形状、管脚束、排列顺序

### 电气特性

- 传输方向和电平范围（什么范围为高电平，什么范围为高电平）

### 功能特性

- 每根传输线的功能
  - 地址
  - 数据
  - 控制

### 时间特性

- 信号的时序关系

## 总线的性能指标

### 宽度

- 数据线的根数

### 标准传输率

- 每秒传输的最大字节数（MBps）

### 时钟同步/异步

- 同步和不同步（≠异步）

### 总线复用

- 地址线与数据线复用（共用的意思）
  - 减少芯片的管脚束

### 信号线数

- 地址线、数据线和控制线的总和
