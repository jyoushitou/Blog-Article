# cmake

## 构建简单文件

```cpp
// 指定CMake版本
cmake_minmum_required(VERSION 3.10)

// 项目名称
project(Project_name)

// 添加源文件到项目
add_executable(Tutorial tutorial.cxx)
```

- 以上是最低的项目构建
- 然后在同级目录下创建build/
- 再进入

```bash
cd build
# 创建项目
cmake (-G "ProjectName") ..(CMakeLists.txt路径)
# 构建项目
cmake --build .
```

- 配好编译器的构建环境，也可以使用**cmake ..**去指定

## 指定c++标准

```cpp
// 设置变量名以指定
set(CMAKE_CXX_STANDARD 11)
// 严格要求指定的标准
set(CMAKE_CXX_STANDARD_REQUIRED True)
// 关闭 GNU 扩展，使用 -std=c++17 而非 -std=gnu++17
set(CMAKE_CXX_EXTENSIONS OFF)
```


### .h.in

- .h.in 是构建系统（主要是 Autoconf / CMake）中使用的模板头文件（template header），结尾的 .in 表示 "input"。它的作用是：在配置阶段被构建工具处理，替换掉其中的占位符/变量，生成最终的 .h 头文件。

- 用来定义变量
