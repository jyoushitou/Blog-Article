## 一、总体架构图

```
┌────────────────────────────┐         HTTP :8080          ┌──────────────────────────────┐
│       Vue 前端 (浏览器)      │  ─────────────────────────►  │      RPCGateway (C++ 网关)    │
│  vue/src/Blog/BlogHome.vue  │                             │  RPCGateway/source/main.cpp   │
└────────────────────────────┘  ◄─────────────────────────  └──────────────────────────────┘
      fetch('/api/articles')          JSON 响应                        │
                                                                     │ TCP :60919（帧协议）
                                                                     ▼
                                                        ┌──────────────────────────────┐
                                                        │       Blog.rs (Rust 服务)      │
                                                        │  Blog/src/Blog.rs             │
                                                        └──────────────────────────────┘
```

## 二、完整函数调用栈

### 链路 1：Vue 前端（浏览器侧）

```text
BlogHome.vue
│
├── onMounted()                        ← 页面挂载时
│     │
│     └── fetchArticles()              ← 拉取文章列表
│           │
│           └── fetch('/api/articles') ← 浏览器发送 HTTP GET 请求
│
└── viewArticle(slug)                  ← 点击文章卡片时
      │
      └── fetch('/api/articles/' + slug)  ← 发送 HTTP GET 请求
```

### 链路 2：RPCGateway（C++ 网关）

```text
main.cpp
│
├── CreateConnection("127.0.0.1", "60919")     ← 连接 Blog.rs
│     └── client->Connect(host, port)
│           └── client->SetMessageCallback(ClientWork)   ← 注册回包回调
│                 └── client->SetCloseCallback(Close)    ← 注册断线回调
│
└── RunHttpServer(60906, 8080)
      │
      ├── http_server->SetHandleVueRequestCallback(HandleVueBiz)  ← 注册业务回调
      │
      └── http_server->StartHttpAccept()
            │
            └── accept HTTP 连接
                  │
                  └── session->Start()
                        │
                        ├── async_read_header                    ← 读 HTTP 请求头
                        │     │
                        │     └── HttpSession::HandleRequest(body) ← 处理请求
                        │           │
                        │           └── http_server->HandleVueRequest(session, path, body)
                        │                 │
                        │                 ├── body 为空 → cmd_str = path
                        │                 │       例："/api/articles"
                        │                 │
                        │                 └── 调用 handle_vue_cb = HandleVueBiz
                        │                       │
                        │                       ▼
                        │                 ┌──────────────────────────────────────┐
                        │                 │  RPCGateWayWork.cpp                  │
                        │                 │  HandleVueBiz(session, path, cmd_str)│
                        │                 └──────────────────────────────────────┘
                        │                       │
                        │                       ├── msg_id = g_net_msg_id.fetch_add(1)
                        │                       │
                        │                       ├── g_pending[msg_id] = {session, path}   ← 记录等回包的会话
                        │                       │
                        │                       └── client->ToSend(msg_id, cmd_str)        ← 发给 Blog.rs
                        │                             │
                        │                             ▼  TCP :60919 + 帧协议
                        │                     【到这里，网关侧转发完毕，返回空字符串表示异步】
                        │
                        ▼
              （等待 ClientWork 回调）
```

当 Blog.rs 回包后：

```text
Blog.rs 返回 JSON
      │
      ▼  TCP :60919
client 收到消息
      │
      └── ClientMessageCallback → ClientWork(msg_id, msg)
            │
            ├── 查 g_pending 表 → 找到 session
            │
            └── session->AsyncSendResponse(msg)
                  │
                  └── boost::asio::post(ioc, ...)      ← 投递到 HTTP io_context 线程
                        │
                        └── HttpSession::HttpSendResponse(body)
                              │
                              └── async_write(sock, response)    ← 把 JSON 回给 Vue
                                    │
                                    └── Start()                   ← Keep-Alive，继续读下一个请求
```

### 链路 3：Blog.rs（Rust 服务）

```text
main.rs
│
└── Blog::listen().await
      │
      ├── TcpListener::bind("0.0.0.0:60919")       ← 绑定端口
      │
      └── loop { listen.accept().await }           ← 循环接受连接
            │
            ├── Ok((sock, addr)) → tokio::spawn(handle_connection(sock))
            │     │
            │     └── handle_connection(mut stream)
            │           │
            │           └── loop
            │                 │
            │                 ├── NetServer::read_frame(&mut stream).await
            │                 │     │
            │                 │     │  ┌─────────────────────────────────────────┐
            │                 │     │  │ NetServer.rs                            │
            │                 │     │  │ read_frame:                             │
            │                 │     │  │  1. 读 12 字节头 (8字节msg_id + 4字节len)│
            │                 │     │  │  2. 校验 len (0 < len ≤ 1MB)             │
            │                 │     │  │  3. 读 len 字节 body                     │
            │                 │     │  │  4. 返回 (msg_id, body)                  │
            │                 │     │  └─────────────────────────────────────────┘
            │                 │     │
            │                 │     ├── Ok((msg_id, msg))
            │                 │     │
            │                 │     ├── cmd = String::from_utf8_lossy(&msg).trim().to_string()
            │                 │     │
            │                 │     ├── json = route(&cmd)
            │                 │     │     │
            │                 │     │     ├── "GetArticleList" | "/api/articles"
            │                 │     │     │     └── mock_article_list()
            │                 │     │     │
            │                 │     │     ├── c if starts_with("GetArticle:")
            │                 │     │     │     └── mock_article_detail(slug)
            │                 │     │     │
            │                 │     │     ├── c if starts_with("/api/articles/")
            │                 │     │     │     └── mock_article_detail(slug)
            │                 │     │     │
            │                 │     │     ├── "GetHealth" | "health"
            │                 │     │     │     └── 健康检查 JSON
            │                 │     │     │
            │                 │     │     └── other
            │                 │     │           └── 404 JSON
            │                 │     │
            │                 │     └── NetServer::write_frame(&mut stream, msg_id, json.as_bytes()).await
            │                 │           │
            │                 │           │  ┌─────────────────────────────────────────┐
            │                 │           │  │ NetServer.rs                            │
            │                 │           │  │ write_frame:                           │
            │                 │           │  │  1. 8字节 msg_id (大端序)               │
            │                 │           │  │  2. 4字节 body长度 (大端序)             │
            │                 │           │  │  3. body 原样写入                       │
            │                 │           │  └─────────────────────────────────────────┘
            │                 │
            │                 └── 循环继续，等待下一条命令 / 连接关闭
```

## 三、完整数据流（以「文章列表」和「文章详情」为例）

### 案例 1：拉取文章列表

#### 第 1 步：Vue 发出 HTTP 请求

```http
GET /api/articles HTTP/1.1
Host: localhost:8080
Accept: application/json
```

#### 第 2 步：网关解析请求

在 `NetHttpServer.cpp` 的 `HttpServer::HandleVueRequest` 中：

```
body = ""（GET 无请求体）
→ cmd_str = path = "/api/articles"
```

#### 第 3 步：网关调用业务回调

```cpp
// RPCGateWayWork.cpp
HandleVueBiz(session, "/api/articles", "/api/articles")
│
├── msg_id = 1001                        ← 全局自增
├── g_pending[1001] = { session, "/api/articles" }
└── client->ToSend(1001, "/api/articles")
```

#### 第 4 步：TCP 帧发送到 Blog.rs

`ToSend` 内部按帧协议打包：

```
┌────────────────┬──────────────────┬──────────────────────────┐
│  msg_id (8B)    │  body_len (4B)    │  body (cmd字符串)        │
│  00 00 00 00    │  00 00 00 0F     │  "/api/articles" (15字节)│
│  00 00 03 E9    │                  │                          │
└────────────────┴──────────────────┴──────────────────────────┘
```

#### 第 5 步：Blog.rs 读取帧

`NetServer::read_frame` 解析出：

```rust
msg_id = 1001
body   = b"/api/articles"
```

#### 第 6 步：路由分发

```rust
cmd = "/api/articles"

route("/api/articles")
  → 匹配第 1 条分支: "GetArticleList" | "/api/articles"
  → 调用 mock_article_list()
  → 返回 JSON 字符串
```

#### 第 7 步：返回 Mock 数据

```json
[
  {
    "slug": "hello-world",
    "title": "Hello World",
    "date": "2024-01-01",
    "tags": ["intro", "rust"],
    "summary": "第一篇博客"
  },
  {
    "slug": "blog-architecture",
    "title": "博客架构设计",
    "date": "2024-02-15",
    "tags": ["architecture", "design"],
    "summary": "网关 + 微服务架构"
  }
]
```

#### 第 8 步：Blog.rs 写帧回网关

```
┌────────────────┬──────────────────┬──────────────────────────────────────────┐
│  msg_id (8B)    │  body_len (4B)    │  body (JSON)                             │
│  00 00 00 00    │  00 00 01 5E     │  [{"slug":"hello-world","title":...}]     │
│  00 00 03 E9    │  350              │                                          │
└────────────────┴──────────────────┴──────────────────────────────────────────┘
```

#### 第 9 步：网关 `ClientWork` 回包

```cpp
ClientWork(1001, "[{\"slug\":\"hello-world\",...}]")
│
├── 从 g_pending 查到 session（msg_id=1001 对应的 HTTP 会话）
└── session->AsyncSendResponse(json)
      └── HttpSendResponse(json)
            └── HTTP/1.1 200 OK, Content-Type: application/json
```

#### 第 10 步：Vue 接收并渲染

```javascript
const data = await res.json()   // data = 文章数组
articles.value = Array.isArray(data) ? data : []
```

Vue 模板渲染：

```html
<div v-for="article in articles" ...>
  <h3>{{ article.title }}</h3>
  <p>{{ article.summary }}</p>
  <span>{{ article.date }}</span>
  <span>{{ article.tags.join(' / ') }}</span>
</div>
```

### 案例 2：查看文章详情

#### 第 1 步：Vue 点击卡片

```javascript
// BlogHome.vue
function viewArticle(slug) {
  fetch('/api/articles/' + slug)     // 例如 slug = "blog-architecture"
}
```

#### 第 2 步：网关解析

```
path = "/api/articles/blog-architecture"
body = ""（GET）
→ cmd_str = "/api/articles/blog-architecture"
```

#### 第 3 步：网关发送帧

```
msg_id = 1002
body   = "/api/articles/blog-architecture"
```

#### 第 4 步：Blog.rs 路由

```rust
cmd = "/api/articles/blog-architecture"

route(cmd)
  ├── 不匹配 "GetArticleList" | "/api/articles"
  ├── 不匹配 starts_with("GetArticle:")
  └── 匹配 c if c.starts_with("/api/articles/")
        │
        ├── slug = trim_start_matches("/api/articles/") = "blog-architecture"
        └── mock_article_detail("blog-architecture")
              │
              └── 返回：
              {
                "slug": "blog-architecture",
                "title": "博客架构设计",
                "date": "2024-02-15",
                "tags": ["architecture", "design"],
                "content": "Vue -> 网关 -> Rust 博客服务。\n\n当前为 mock 模式，尚未接入 MySQL。"
              }
```

#### 第 5 步：回传链路（与列表同理）

```
Blog.rs → 帧(msg_id=1002, JSON) → 网关 ClientWork(1002, json) 
       → session->AsyncSendResponse(json) → HTTP 200 → Vue viewArticle()
```

## 四、数据流汇总表

| 阶段           | 数据形态            | 示例                                                      | 协议/载体             |
| -------------- | ------------------- | --------------------------------------------------------- | --------------------- |
| Vue → 网关     | HTTP 请求           | `GET /api/articles/blog-architecture`                     | HTTP/1.1 :8080        |
| 网关解析       | 命令字符串          | `cmd_str = "/api/articles/blog-architecture"`             | 内存                  |
| 网关 → Blog.rs | 帧（msg_id + cmd）  | `[1002][长度]["/api/articles/blog-architecture"]`         | TCP :60919 帧协议     |
| Blog.rs 读取   | `(u64, Vec<u8>)`    | `(1002, b"/api/articles/blog-architecture")`              | NetServer::read_frame |
| Blog.rs 路由   | `RouteResult`       | `route("...") → mock_article_detail("blog-architecture")` | 内存                  |
| Blog.rs 返回   | JSON 字符串         | `{"slug":"blog-architecture",...}`                        | 内存                  |
| Blog.rs → 网关 | 帧（msg_id + JSON） | `[1002][长度][{"slug":"blog-architecture",...}]`          | TCP :60919 帧协议     |
| 网关回包       | HTTP Response       | `200 OK {"slug":"blog-architecture",...}`                 | HTTP/1.1 :8080        |
| Vue 渲染       | 浏览器 JS 对象      | `const data = await res.json()`                           | 内存                  |

## 五、关键代码对应关系

### 帧协议格式（网关与 Blog.rs 之间统一）

```
┌─────────────────────┬─────────────────────┬─────────────────────────┐
│ msg_id: u64 (8字节)  │ body_len: u32 (4字节)│ body: Vec<u8> (可变长度) │
│ 大端序 (BE)          │ 大端序 (BE)          │ 命令字符串或 JSON 数据   │
└─────────────────────┴─────────────────────┴─────────────────────────┘
```

**Rust 侧（NetServer.rs）：**

```rust
// 读帧
let msg_id = u64::from_be_bytes(...);   // 8字节大端
let msg_len = u32::from_be_bytes(...);  // 4字节大端
stream.read_exact(&mut body).await;     // 读消息体

// 写帧
buf.extend_from_slice(&msg_id.to_be_bytes());   // 8字节大端
buf.extend_from_slice(&(body.len() as u32).to_be_bytes()); // 4字节大端
buf.extend_from_slice(body);
```

**C++ 侧（网关客户端 `ToSend`）** 使用相同格式，所以能互通。

### 命令字符串映射

| Vue 请求路径                          | 网关转发给 Blog.rs 的命令         | Blog.rs 路由分支                                                             |
| ------------------------------------- | --------------------------------- | ---------------------------------------------------------------------------- |
| `GET /api/articles`                   | `/api/articles`                   | `"GetArticleList" \| "/api/articles"` → `mock_article_list()`                |
| `GET /api/articles/hello-world`       | `/api/articles/hello-world`       | `starts_with("/api/articles/")` → `mock_article_detail("hello-world")`       |
| `GET /api/articles/blog-architecture` | `/api/articles/blog-architecture` | `starts_with("/api/articles/")` → `mock_article_detail("blog-architecture")` |
| `GET /health`                         | `/health`                         | `"GetHealth" \| "health"` → 健康检查 JSON                                    |
| 任意其他                              | 原样透传                          | `other => 404 JSON`                                                          |

## 六、一次性完整链路（文字版）

**Vue 首页加载文章列表：**

```
BlogHome.vue onMounted()
  → fetchArticles()
    → fetch('/api/articles')
      → [HTTP :8080]
      → C++ HttpServer::StartHttpAccept()
        → HttpSession::Start()
          → async_read_header → HandleRequest("")
            → HttpServer::HandleVueRequest(session, "/api/articles", "")
              → cmd_str = "/api/articles"
              → HandleVueBiz(session, "/api/articles", "/api/articles")
                → msg_id = 1001
                → g_pending[1001] = {session, "/api/articles"}
                → client->ToSend(1001, "/api/articles")
                  → [TCP :60919 帧]
                  → Rust Blog::listen()
                    → handle_connection(stream)
                      → NetServer::read_frame(stream)
                        → (1001, b"/api/articles")
                        → cmd = "/api/articles"
                        → route(&cmd)
                          → mock_article_list()
                          → JSON 字符串
                      → NetServer::write_frame(stream, 1001, json)
                        → [TCP :60919 帧]
                        → C++ ClientWork(1001, json)
                          → g_pending[1001].session->AsyncSendResponse(json)
                            → async_write(sock, HTTP Response)
                              → [HTTP :8080]
                              → Vue res.json() → articles.value = data
```
