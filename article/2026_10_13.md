# c++

## static_cast< T >

`static_cast<T>(expr)` 是 C++ 中最常用的强制类型转换之一，在**编译期**完成类型检查，属于"静态"转换，不依赖运行时类型识别（RTTI）。

### 基本语法

```cpp
static_cast<目标类型>(表达式)
```

### 常见用途

1. **基本数据类型之间的转换**

```cpp
double d = 3.14;
int i = static_cast<int>(d);   // 3，隐式转换的显式写法

char c = 'A';
int code = static_cast<int>(c); // 65，拿到字符编码
```

2. **有继承关系的指针/引用转换**

向上转换（派生类 -> 基类）总是安全的；向下转换（基类 -> 派生类）由程序员自己保证正确性，不做运行时检查。

```cpp
class Base { public: virtual ~Base() = default; };
class Derived : public Base { public: void foo() {} };

Derived* d = new Derived();
Base* b = static_cast<Base*>(d);        // 向上转换，安全
Derived* d2 = static_cast<Derived*>(b); // 向下转换，不安全，需自行确认
```

3. **把 void\* 转回具体类型指针**

```cpp
void* p = malloc(sizeof(int));
int* ip = static_cast<int*>(p);
```

4. **消除隐式转换的警告，表明意图**

```cpp
int a = 10, b = 3;
double r = static_cast<double>(a) / b; // 避免整数除法
```

5. **转成右值引用（std::move 的底层机制）**

```cpp
std::string s = "hello";
std::string&& rref = static_cast<std::string&&>(s);
```

### 与其它转换的区别

| 转换方式           | 检查时机 | 典型场景                                           |
| ------------------ | -------- | -------------------------------------------------- |
| `static_cast`      | 编译期   | 数值转换、继承体系内转换、void\* 还原              |
| `dynamic_cast`     | 运行时   | 多态类型的向下/交叉转换，失败返回 nullptr 或抛异常 |
| `const_cast`       | 编译期   | 增删 const / volatile 限定                         |
| `reinterpret_cast` | 编译期   | 底层比特重新解释，极度危险                         |

### 注意事项

- `static_cast` **不做运行时检查**，向下转换若类型不符会导致未定义行为；多态场景应优先用 `dynamic_cast`。
- 无法去除 `const` 限定，需要 `const_cast`。
- 相比 C 风格 `(int)d`，`static_cast` 更明确、更易被检索，也更安全。
- 指针与整数之间的转换不能用 `static_cast`（需 `reinterpret_cast`）。

## dynamic_cast< T >

`dynamic_cast<T>(expr)` 是唯一在**运行时**做类型检查的转换，依赖 RTTI，专门用于多态类型的安全向下/交叉转换。

### 基本语法

```cpp
dynamic_cast<目标类型>(表达式)
```

### 前提条件

- 目标类型必须是指针或引用。
- 源类型必须是**多态类型**（即基类至少有一个虚函数），否则编译不过。
- 需要编译器开启 RTTI（部分项目用 `-fno-rtti` 关闭后不可用）。

### 常见用途

1. **向下转换，并判断是否成功**

```cpp
class Base { public: virtual ~Base() = default; };
class Derived : public Base { public: void foo() {} };

Base* b = new Derived();
if (Derived* d = dynamic_cast<Derived*>(b)) {
    d->foo();          // 转换成功
} else {
    // 转换失败，d 为 nullptr
}
```

2. **引用版本，失败时抛异常**

```cpp
Base& rb = *b;
try {
    Derived& rd = dynamic_cast<Derived&>(rb);
    rd.foo();
} catch (const std::bad_cast& e) {
    // 转换失败会抛 std::bad_cast
}
```

3. **交叉转换（cross cast）**

多个基类之间的指针互转，`static_cast` 做不到，只能用 `dynamic_cast`。

```cpp
// class Derived : public A, public B { ... };
A* pa = new Derived();
B* pb = dynamic_cast<B*>(pa); // 从 A* 转到 B*
```

### 返回值规则

| 目标类型 | 成功     | 失败               |
| -------- | -------- | ------------------ |
| 指针     | 有效指针 | `nullptr`          |
| 引用     | 有效引用 | 抛 `std::bad_cast` |

### 注意事项

- 有**运行时开销**（要查询 RTTI 信息），性能敏感路径慎用。
- 对非多态类型、或转换到无关类型，编译期就会报错。
- 判断类型时更推荐用 `virtual` 函数或 `typeid`，`dynamic_cast` 泛滥通常意味着设计有问题。

## const_cast< T >

`const_cast<T>(expr)` 用于**增删 `const` / `volatile` 限定**，是四种转换里唯一能去掉 `const` 的。

### 基本语法

```cpp
const_cast<目标类型>(表达式)
```

目标类型与源类型必须只差 `const` / `volatile` 限定，否则编译不过。

### 常见用途

1. **去掉 const，用于调用只接收非 const 参数的旧接口**

```cpp
void legacy_api(char* s); // 老接口，不接受 const

const char* msg = "hello";
legacy_api(const_cast<char*>(msg)); // 仅在不修改字符串时使用
```

2. **在 const 成员函数里修改被 mutable 允许的成员之外的数据（谨慎）**

```cpp
class Foo {
    int cache_;
public:
    int value() const {
        // 只是想复用已有逻辑，并不真的写入
        return const_cast<Foo*>(this)->compute();
    }
    int compute() { return cache_ = 42; }
};
```

3. **为重载的非 const / const 版本复用代码**

```cpp
const int& operator[](std::size_t i) const {
    return const_cast<int&>(static_cast<const Container&>(*this)[i]);
}
```

### 注意事项

- 如果原始对象**本身定义就是 const**，通过 `const_cast` 去写它是**未定义行为**。
- 只有底层对象本来是非 const、只是通过 const 指针/引用访问时，去掉 const 再写才是安全的。
- `const_cast` 只能改限定符，不能改类型。

## reinterpret_cast< T >

`reinterpret_cast<T>(expr)` 是**最危险**的转换，只是把同一段比特按新类型重新解释，不做任何数值或类型检查。

### 基本语法

```cpp
reinterpret_cast<目标类型>(表达式)
```

### 常见用途

1. **指针与整数之间互转**

```cpp
uintptr_t addr = reinterpret_cast<uintptr_t>(ptr);
void* p = reinterpret_cast<void*>(addr);
```

2. **不同类型指针之间互转**

```cpp
int* ip = ...;
char* cp = reinterpret_cast<char*>(ip); // 按字节查看内存
```

3. **配合底层库，读写序列化/内存布局**

```cpp
struct Header { uint32_t magic; };
char buf[64];
Header* h = reinterpret_cast<Header*>(buf);
```

### 注意事项

- **平台相关**、结果不可移植，且极易触发对齐问题和未定义行为。
- 与 `static_cast` 不同，它不做任何有意义的转换，只是"换个视角看这段内存"。
- 除非在做底层编程（序列化、硬件、类型双关），否则应避免使用；类型双关更推荐 `std::memcpy` 或 `std::bit_cast`（C++20）。

### 四种转换总览

| 转换方式           | 检查时机 | 能否去 const | 典型场景                              |
| ------------------ | -------- | ------------ | ------------------------------------- |
| `static_cast`      | 编译期   | 否           | 数值转换、继承体系内转换、void\* 还原 |
| `dynamic_cast`     | 运行时   | 否           | 多态类型的向下/交叉转换               |
| `const_cast`       | 编译期   | 是           | 增删 const / volatile 限定            |
| `reinterpret_cast` | 编译期   | 否           | 底层比特重新解释、指针↔整数           |

## 它们属于哪个库 / 头文件

四种强制类型转换本身**不属于任何库**，它们是**语言内建的关键字（cast operator）**，和 `+`、`*` 一样由编译器直接支持，**无需 `#include` 任何头文件**。

但使用时会涉及一些标准库里的**辅助类型**：

| 用到的东西                                                         | 所属头文件       | 说明                                                 |
| ------------------------------------------------------------------ | ---------------- | ---------------------------------------------------- |
| `static_cast` / `dynamic_cast` / `const_cast` / `reinterpret_cast` | 无（语言内建）   | 关键字，无需 include                                 |
| `std::bad_cast`                                                    | `<typeinfo>`     | `dynamic_cast` 引用版失败时抛出的异常                |
| `std::type_info` / `typeid`                                        | `<typeinfo>`     | RTTI 类型信息                                        |
| `std::bit_cast`                                                    | `<bit>`（C++20） | 安全的类型双关，可替代 `reinterpret_cast` 的常见用法 |
| `uintptr_t` / `intptr_t`                                           | `<cstdint>`      | 指针与整数互转时的常用整数类型                       |
| `std::move` / `std::forward`                                       | `<utility>`      | 底层就是用 `static_cast` 实现的                      |

```cpp
#include <typeinfo>  // std::bad_cast, typeid
#include <cstdint>   // uintptr_t
#include <utility>   // std::move, std::forward
// 而 static_cast 等本身不需要任何头文件
```
