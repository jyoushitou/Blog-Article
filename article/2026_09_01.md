# 解析GET
## Boost.Beast 收到后

```
req.method()  == "GET"
req.target()  == "/api/articles?page=1&pageSize=10&tag=vue&keyword=%E5%85%A5%E9%97%A8"
req.body()    == ""   ← GET 的 body 是空的，没有 JSON！
```

- **所以：GET 根本不需要 `json::parse`，只需要解析字符串。** 
- 但是POST需要parse进行获取传入的数据

## 从 target 拆出 path 和 query

```cpp
std::string target = req.target();
// 之前的赋值的target = "/api/articles?page=1&pageSize=10&tag=vue&keyword=%E5%85%A5%E9%97%A8"

std::string path;
std::string query;

size_t qpos = target.find('?');//查找问号

if (qpos == std::string::npos) {
    // 没有问号，说明没有查询参数
    path  = target;
    query = "";
} else {
    path  = target.substr(0, qpos);        // "/api/articles"
    query = target.substr(qpos + 1);       // "page=1&pageSize=10&tag=vue&keyword=%E5%85%A5%E9%97%A8"
}
```
- path：发来的路径
- query：？后面的内容
## 按 `&` 拆成多个参数对

```cpp
// query = "page=1&pageSize=10&tag=vue&keyword=%E5%85%A5%E9%97%A8"

std::stringstream ss(query);
std::string pair;

while (std::getline(ss, pair, '&')) {
    // 第一次循环 pair = "page=1"
    // 第二次循环 pair = "pageSize=10"
    // 第三次循环 pair = "tag=vue"
    // 第四次循环 pair = "keyword=%E5%85%A5%E9%97%A8"
    std::cout << pair << std::endl;
}
```
## 按 `=` 拆出 key 和 value

```cpp
std::stringstream ss(query);
std::string pair;

while (std::getline(ss, pair, '&')) {
    size_t pos = pair.find('=');
    std::string key   = pair.substr(0, pos);   // "page"
    std::string value = pair.substr(pos + 1);  // "1"
}
```
## URL 解码 value（处理中文）

```cpp
std::string url_decode(const std::string& str) {
    std::string out;
    for (size_t i = 0; i < str.size(); ++i) {
        if (str[i] == '%' && i + 2 < str.size()) {
            auto hex_val = [](char c) -> int {
                if (c >= '0' && c <= '9') return c - '0';
                if (c >= 'a' && c <= 'f') return c - 'a' + 10;
                if (c >= 'A' && c <= 'F') return c - 'A' + 10;
                return -1;
            };
            int hi = hex_val(str[i + 1]);
            int lo = hex_val(str[i + 2]);
            if (hi != -1 && lo != -1) {
                out += static_cast<char>((hi << 4) | lo);  // 两个十六进制拼成一个字节
                i += 2;
                continue;
            }
        }
        if (str[i] == '+')
            out += ' ';   // URL 里 + 号表示空格
        else
            out += str[i];
    }
    return out;
}
```
## 合并成完整解析函数（存进 map）

```cpp
std::map<std::string, std::string> parse_query(const std::string& query) {
    std::map<std::string, std::string> params;

    if (query.empty()) return params;

    std::stringstream ss(query);
    std::string pair;

    while (std::getline(ss, pair, '&')) {
        size_t pos = pair.find('=');
        if (pos == std::string::npos) continue;  // 保险：没有 = 就跳过

        std::string key   = url_decode(pair.substr(0, pos));
        std::string value = url_decode(pair.substr(pos + 1));

        params[key] = value;
    }

 
 return params;
}
```
