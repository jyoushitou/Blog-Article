# c++

# 智能指针

- 智能指针本质是 **RAII**：把资源交给栈对象的析构函数管理，离开作用域自动释放

## 三种智能指针

| 类型         | 头文件     | 语义                   | 拷贝                | 典型场景                   |
| ------------ | ---------- | ---------------------- | ------------------- | -------------------------- |
| `unique_ptr` | `<memory>` | 独占所有权             | 禁止拷贝，只能 move | 默认首选，替代裸 `new`     |
| `shared_ptr` | `<memory>` | 共享所有权（引用计数） | 可拷贝/移动         | 多方共享同一对象           |
| `weak_ptr`   | `<memory>` | 弱引用（不增加计数）   | 可拷贝              | 打破 `shared_ptr` 循环引用 |

## unique_ptr

- 独占，同一时刻只有一个所有者
- 不能拷贝，只能 `std::move` 转移所有权
- 大小与裸指针相同，**零开销**

```cpp
std::unique_ptr<int> p = std::make_unique<int>(42);
// std::unique_ptr<int> q = p;          // 错误：禁止拷贝
std::unique_ptr<int> q = std::move(p);  // 正确：转移所有权，p 变为 nullptr

if (p == nullptr) { /* p 已被转移 */ }
```

- 自定义删除器（析构时释放资源）：

```cpp
std::unique_ptr<FILE, decltype(&fclose)> fp(fopen("a.txt", "r"), &fclose);
```

## shared_ptr

### 引用计数

- 内部维护引用计数，每拷贝一次 +1，析构一次 -1
- 计数归零时释放对象

```cpp
std::shared_ptr<int> a = std::make_shared<int>(10); // count = 1
std::shared_ptr<int> b = a;                          // count = 2
std::cout << a.use_count();                          // 2
b.reset();                                           // count = 1
```

### 控制块（Control Block）

- `shared_ptr` 由 **对象指针 + 控制块指针** 组成（所以大小为裸指针的两倍）
- 控制块保存：引用计数、弱引用计数、删除器、分配器

```cpp
对象指针 ─────► [ 对象数据 ]
控制块指针 ───► [ 强引用计数 | 弱引用计数 | 删除器 | 分配器 ]
```

### 常见的坑

```cpp
int* raw = new int(5);
std::shared_ptr<int> p1(raw);
std::shared_ptr<int> p2(raw); // 错误！两个独立控制块 → double free

// 正确做法
std::shared_ptr<int> p3 = std::make_shared<int>(5);
```

- **优先 `make_shared`**：一次分配（对象 + 控制块连续内存），异常安全，效率更高

## weak_ptr

- 指向 `shared_ptr` 管理的对象，但**不增加强引用计数**
- 不能直接解引用，需要 `lock()` 升级为 `shared_ptr`

```cpp
std::shared_ptr<int> sp = std::make_shared<int>(10);
std::weak_ptr<int> wp = sp;

if (auto locked = wp.lock()) {  // 对象还活着
    std::cout << *locked;
} else {
    // 对象已释放
}
```

- `expired()` 判断对象是否已销毁

### 循环引用问题

- 两个 `shared_ptr` 互相指向对方 → 计数永远不为 0 → 内存泄漏

```cpp
struct Node {
    std::shared_ptr<Node> next;
    // std::weak_ptr<Node> prev; // ← 其中一方改成 weak_ptr 即可打破循环
};
```

## 智能指针转换（pointer_cast）

对不同类型 `shared_ptr` / `weak_ptr` 做转换，**保留控制块与引用计数**，避免裸指针转换造成二次释放。

| 函数                       | 等价于                      | 场景                                 |
| -------------------------- | --------------------------- | ------------------------------------ |
| `static_pointer_cast`      | `static_cast`               | 向上/向下转型，无运行时检查，最快    |
| `dynamic_pointer_cast`     | `dynamic_cast`              | 多态类型向下转型，失败返回 `nullptr` |
| `const_pointer_cast`       | `const_cast`                | 添加/移除 `const`                    |
| `reinterpret_pointer_cast` | `reinterpret_cast`（C++17） | 位级重新解释                         |

```cpp
std::shared_ptr<Base> b = std::make_shared<Derived>();

// 错误：用 get() 构造新 shared_ptr → 独立控制块 → double free
// std::shared_ptr<Derived> bad(static_cast<Derived*>(b.get()));

// 正确：共享同一控制块，引用计数 +1
std::shared_ptr<Derived> d = std::static_pointer_cast<Derived>(b);
```

- `static_pointer_cast`：**不做运行时检查**，类型不匹配是未定义行为
- 向下转型不确定时用 `dynamic_pointer_cast`（失败返回 `nullptr`，更安全）

## 使用建议

- 默认用 `unique_ptr`，确实需要共享再用 `shared_ptr`
- 优先 `make_unique` / `make_shared`，避免裸 `new`
- 只传 **借用**（不转移所有权）时用裸指针或引用，不要传 `shared_ptr` 值
- 打破循环引用用 `weak_ptr`
- 不要用 `get()` 的返回值去构造另一个智能指针
